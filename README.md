# 📚 آکادمی سبحان صمدی — کتاب‌های صوتی

یک وب اپلیکیشن حرفه‌ای برای پخش و مدیریت کتاب‌های صوتی آکادمی سبحان صمدی.

## ✨ ویژگی‌ها

- 🎧 **پلیر صوتی حرفه‌ای** با کنترل کامل (پخش، توقف، جلو/عقب ۱۵ ثانیه)
- 📖 **کتابخانه کامل** با ۱۲+ کتاب صوتی ترجمه‌شده
- 🔍 **جستجوی زنده** در میان تمام کتاب‌ها
- 🏷️ **فیلتر و مرتب‌سازی** بر اساس موضوع، نام، امتیاز
- 🌙 **دارک / لایت مود** با ذخیره در localStorage
- 🔖 **بوکمارک** برای ذخیره موقعیت مطالعه
- ⏰ **تایمر خواب** (Sleep Timer)
- ⚡ **سرعت پخش** قابل تنظیم (۰.۵× تا ۲×)
- 📱 **طراحی واکنش‌گرا** (Responsive) برای موبایل، تبلت و دسکتاپ
- 🎨 **انیمیشن‌های حرفه‌ای** با Particles و Swiper Slider
- ⌨️ **کیبورد شورتکات** (Space = پخش/توقف، Arrow = جابجایی)
- 🎵 **Media Session API** برای کنترل از نوتیفیکیشن گوشی

## 🚀 راه‌اندازی

### روش ۱: مستقیم در مرورگر
فایل `index.html` را در مرورگر باز کنید.

### روش ۲: GitHub Pages
1. ریپو را روی GitHub آپلود کنید
2. به Settings > Pages بروید
3. Source را روی `main branch` تنظیم کنید
4. لینک سایت آماده می‌شود

## 🎵 اضافه کردن فایل‌های صوتی

برای هر کتاب در `js/data.js`، فایل‌های MP3 را در فیلد `src` هر فصل قرار دهید:

```javascript
chapters: [
  { title: "فصل ۱", duration: "۴۵:۲۰", src: "audio/book1/chapter1.mp3" },
  { title: "فصل ۲", duration: "۵۲:۱۰", src: "audio/book1/chapter2.mp3" }
]
```

یا می‌توانید از لینک‌های خارجی (CDN) استفاده کنید:
```javascript
{ title: "فصل ۱", duration: "۴۵:۲۰", src: "https://cdn.example.com/book1-ch1.mp3" }
```

## 🛠️ تکنولوژی‌ها

- **HTML5 + CSS3 + Vanilla JavaScript** — بدون فریم‌ورک
- **Swiper.js** — اسلایدر حرفه‌ای
- **Font Awesome** — آیکون‌ها
- **Vazirmatn** — فونت فارسی
- **Canvas API** — انیمیشن ذرات پس‌زمینه
- **Web Audio API + MediaSession API** — پلیر حرفه‌ای
- **localStorage** — ذخیره تنظیمات و بوکمارک‌ها
